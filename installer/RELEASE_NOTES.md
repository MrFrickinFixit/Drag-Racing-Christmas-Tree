## Drag Tree 1.0.2

- Added a custom drag-racing Christmas tree icon to the application executable, window/taskbar, installer, shortcuts, and installed-app entry.
- Added a main-window screenshot to the GitHub README.
- Included nine icon sizes from 16 to 256 pixels for clear rendering across Windows display scales.
- Retains the three-second results banner and two-player pre-stage warnings introduced in 1.0.1.

**Download:** Use `DragTree-1.0.2-win-x64-Setup.exe` for installation, or `DragTree-1.0.2-win-x64.zip` for portable use. Both packages include .NET. The installer upgrades earlier versions and preserves racer key preferences.

**Requirements:** Windows 10 22H2 or Windows 11, x64. Packages are unsigned. Download checksums are provided in `SHA256SUMS.txt`.

This is a practice tool. Display, operating-system, and input latency affect measurements; the application is not calibrated track timing equipment.
