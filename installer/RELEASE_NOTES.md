Drag Tree is a Windows drag-racing reaction trainer with single-player and head-to-head racing.

- Sportsman, Pro, and Top Fuel presets with verified countdown timing.
- Independent hold-to-stage and release-to-launch controls with configurable racer keys.
- Optional racer names, reaction times from the final amber and green, recent results, and session statistics.
- One-second incremental staging, false-start detection, timeouts, and a two-second winner banner.
- A nighttime drag-strip theme with a centered, functional Christmas tree.

**Download:** Use `DragTree-1.0.0-win-x64-Setup.exe` for normal installation, or the ZIP for portable use. The Windows x64 packages include .NET; no separate runtime installation is needed. The installer creates a Start-menu shortcut and offers an optional desktop shortcut. It installs for the current user without requiring administrator access.

**Requirements:** Windows 10 22H2 or Windows 11, x64. These initial packages are unsigned. Check `SHA256SUMS.txt` against the download if desired.

This is a practice tool. Display, operating-system, and input latency affect measurements; the application is not calibrated track timing equipment.
