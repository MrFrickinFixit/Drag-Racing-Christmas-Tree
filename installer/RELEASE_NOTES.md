**Download:** Use `PracticeTree-1.1.0-win-x64-Setup.exe` for installation, or `PracticeTree-1.1.0-win-x64.zip` for portable use. Both include .NET. Install the new version over an existing Drag Tree installation to upgrade; the installer may retain the previous installation directory.

**Requirements:** Windows 10 22H2 or Windows 11, x64. Packages are unsigned. Download checksums are provided in `SHA256SUMS.txt`.
