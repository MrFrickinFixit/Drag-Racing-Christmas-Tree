## Drag Tree 1.0.3

- Removed the duplicate Top Fuel tree option. Racers now choose Sportsman or Pro.
- Pro retains the same 0.400-second simultaneous-amber countdown used by Top Fuel racing.
- Updated the on-screen timing guidance, documentation, and main-window screenshot to match the simplified selector.
- Retains the custom app/installer icons, configurable keys, three-second results banner, and two-player pre-stage warnings.

**Download:** Use `DragTree-1.0.3-win-x64-Setup.exe` for installation, or `DragTree-1.0.3-win-x64.zip` for portable use. Both packages include .NET. The installer upgrades earlier versions and preserves racer key preferences.

**Requirements:** Windows 10 22H2 or Windows 11, x64. Packages are unsigned. Download checksums are provided in `SHA256SUMS.txt`.

This is a practice tool. Display, operating-system, and input latency affect measurements; the application is not calibrated track timing equipment.
