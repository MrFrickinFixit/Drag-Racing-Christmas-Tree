## Drag Tree 1.0.1

- Race-results banners now remain visible for three seconds.
- In two-player mode, an amber PRE-STAGE warning appears on the waiting racer's panel when their opponent is fully staged.
- The warning identifies the racer and their configured key, and clears when they pre-stage, the opponent unstages, or the race is canceled.
- Added regression coverage for both player lanes and the updated banner duration.

**Download:** Use `DragTree-1.0.1-win-x64-Setup.exe` for installation, or `DragTree-1.0.1-win-x64.zip` for portable use. Both packages include .NET; no separate runtime installation is required. The installer upgrades version 1.0.0 using the same AppId and preserves racer key preferences.

**Requirements:** Windows 10 22H2 or Windows 11, x64. Packages are unsigned. Download checksums are provided in `SHA256SUMS.txt`.

This is a practice tool. Display, operating-system, and input latency affect measurements; the application is not calibrated track timing equipment.
